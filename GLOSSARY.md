# GLOSSARY

Термины домена деплоя (контракт с api-репозиторием, модель ADR-0001 «каждый репозиторий деплоит себя»).

- **Staging-окружение** — среда, обновляемая пушем в `main`. UI-деплой обновляет там только UI-версию, API-версию не трогает.
- **Develop-окружение** — среда для ветки `develop`; устроено как staging, но обновляется своим окружением.
- **CD-триггер** — шаг фронтендового CI, который после публикации UI-образа запускает Deploy workflow в API-репозитории.
- **ui_sha** — полный 40-символьный SHA UI-коммита, чей образ уже опубликован в GHCR; параметр запуска деплоя.
- **API_DEPLOY_PAT** — fine-grained PAT с правом запускать Actions только в API-репозитории; хранится в Encrypted Secrets этого репозитория.
